### Lesson 1.1: What is Web Development?
**Type:** LESSON

**Offline:** true

Key topics:
- Frontend vs Backend development
- Technologies involved (HTML, CSS, JavaScript)
- How the web works

**Type:** TEXT
**Offline:** true

**HTML (HyperText Markup Language)** - Provides structure and content

## Module 2: HTML Basics

### Lesson 2.1: Introduction to HTML
**Type:** LESSON
**Duration:** 1200
**Offline:** true

HTML stands for HyperText Markup Language. It is the standard markup language used to create web pages. HTML uses tags and elements to structure content.

Common elements:
- Headings: h1 through h6
- Paragraphs: p
- Links: a
- Images: img

---

### Content 2.2: HTML Structure
**Type:** TEXT
**Offline:** true

A basic HTML document has:
- DOCTYPE declaration
- html element
- head element (contains metadata)
- body element (contains visible content)

## Module 3: CSS Styling

### Lesson 3.1: Introduction to CSS
**Type:** LESSON
**Duration:** 1500
**Offline:** true

CSS (Cascading Style Sheets) is used to style HTML elements. CSS works by selecting HTML elements and applying style properties to them.

Three ways to apply CSS:
- Inline styles
- Internal stylesheets
- External stylesheets

---

### Content 3.2: CSS Selectors
**Type:** TEXT
**Offline:** true

**CSS Selectors:**
- Element selector: p (all p elements)
- Class selector: .classname
- ID selector: #idname

**Common properties:**
- color: text color
- background-color: background
- font-size: text size
- margin: space outside
- padding: space inside

## Module 4: JavaScript

### Lesson 4.1: JavaScript Basics
**Type:** LESSON
**Duration:** 1800
**Offline:** true

JavaScript is a programming language that runs in the browser. It enables interactivity on web pages by responding to user events like clicks and scrolling.

JavaScript can:
- Respond to user events
- Manipulate HTML elements
- Change CSS styles dynamically
- Send data to servers

---

### Content 4.2: Variables
**Type:** TEXT
**Offline:** true

Variables are containers for storing data. You can create variables using let, const, or var.

**Data types:**
- String: "Hello"
- Number: 42
- Boolean: true/false
- Array: [1, 2, 3]
- Object: { name: "John" }
