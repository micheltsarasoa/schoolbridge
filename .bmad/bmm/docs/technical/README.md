# Technical Documentation

This directory contains technical documentation related to the SchoolBridge LMS, including:

*   **Technical Architecture Document:** Detailed description of the system's architecture, including data layers, offline synchronization, and API design.
*   **Test Strategy & Procedures:** Outlines the testing approach and procedures for the project.
*   **Implementation Guide & Getting Started:** Provides guidance for developers on setting up and working with the project.
*   **Complete Database Setup:** Details the steps for setting up the project's database.
*   **CI/CD Setup:** Information regarding Continuous Integration and Continuous Deployment pipelines.
*   **Database Schema Analysis:** Documents the analysis of the database schema.
*   **Database Structure:** Provides an overview of the database organization.
*   **Sentry Setup:** Details the configuration and usage of Sentry for error tracking.
