## Core Principles

### I. AI-Driven Development

The project will be primarily developed by AI agents. All code, documentation, and other artifacts will be generated by AI. Human intervention will be limited to providing guidance or solving the impossibleor tasks too expensive for the AI , reviewing and approving AI-generated work.


### II. Human-in-the-Loop

While AI drives development, a human developer is always in the loop. The human developer is responsible for defining the project's goals, providing feedback to the AI, and making final decisions. The AI is a tool to augment the human developer, not replace them.


### III. Modular Architecture

The project will be built using a modular architecture. Each component will be a self-contained module with a well-defined API. This will allow for independent development, testing, and deployment of components.


### IV. Test-Driven Development

All code will be developed using a test-driven development (TDD) methodology. Tests will be written before the code, and the code will be written to pass the tests. This will ensure that the code is well-tested and meets the requirements.


### V. Continuous Integration and Deployment

The project will use a continuous integration and deployment (CI/CD) pipeline. All code changes will be automatically built, tested, and deployed to a staging environment. This will ensure that the code is always in a deployable state.


## Technology Stack


The project will be built using the following technologies: Next.js, TypeScript, Tailwind CSS, Prisma, and PostgreSQL.
